This entry sums up Tuesday 24 November 2026's world news in one 1024x1024 picture: 37 stories in total, led by 13 illustrated cards covering COP31's collapse in Antalya, the ICJ genocide ruling on Myanmar, 24 dead in the Banten factory fire, and a 258-seat US House majority. Around the cards sit a seven-number strip, a pinned world map, a UTC timeline and a 24-line ledger, plus a printed date check that separates the day's news from older and not-yet stories. The page is rendered once and shipped as data in art.png, and main.py copies it deterministically to the output directory.

## Run it

```sh
python3 main.py
```
